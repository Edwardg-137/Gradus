# Definición de Gradus

La [propuesta de Gradus para el track 2 EdTech](Gradus_propuesta_hackathon.md) reúne la visión de producto, el alcance del MVP, las reglas de evaluación y recompensa, el catálogo inicial, el banco de ejercicios y el guion de demostración.

La [preparación del pitch de básico a diversificado](Gradus_preparacion_pitch.md) organiza las mejoras propuestas, el caso simulado con un colegio y las decisiones para un piloto.

El enlace del repositorio a la [definición de Nexora](../definicion-nexora/README.md) se conserva como acceso a esa documentación.
