# Gradus

Gradus es una aplicación de estudio para practicar ecuaciones lineales. La [definición del MVP](definicion/README.md) describe la propuesta y el banco de ejercicios.

## Ejecutar en local

Con Node.js 24 o superior, ejecuta `npm start` y abre [Gradus](http://127.0.0.1:3000). `npm test` ejecuta las pruebas.

Las sesiones de invitado se guardan en `data/gradus.sqlite`. El navegador conserva la sesión mediante una cookie y el archivo permite recuperarla después de reiniciar el servidor.
